# Christmas Linux

Собственный дистрибутив Linux для Termux.

## Установка

1. Скачайте Installer.py
2. Запустите: `python Installer.py`
3. Запустите систему: `bash Start.sh`

## Команды

- `Christmas-Help` - Справка по системе
- `Christmas-Info` - Информация о системе  
- `Christmas-Pkg` - Управление пакетами
- `Christmas-Update` - Обновление системы

## Пакетные менеджеры

- `apk` - Основной пакетный менеджер
- `pip3` - Python пакеты
- `npm` - Node.js пакеты
